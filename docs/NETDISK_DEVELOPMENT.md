# 网盘源开发

CokeTV 只有 drpy3 源引擎；网盘账号、分享展开与取播放地址由独立宿主服务管理。源负责搜索和返回用户有权访问的分享链接，宿主负责按账号读取目录和获取临时媒体地址。

## drpy3 详情返回

```js
export default {
    meta: {title: '我的资源源', lang: 'dr3'},
    rule: {},
    async detail(ctx, id) {
        // 用自己的请求逻辑获取分享，示例仅展示返回契约。
        const share = id;
        return {list: [{
            vod_id: id,
            vod_name: '资源名称',
            vod_play_from: '网盘',
            vod_play_url: '分享$' + share,
        }]};
    },
};
```

支持115与光鸭的标准分享链接，以及既有 `push://` 编码分享形式。不要将账号Cookie或Token塞入播放地址、vod_id、图片URL或日志。详情返回标准分享后，宿主展开为作用域内的分集引用；`coketv-netdisk:` 等内部引用应由宿主处理，不重新交给源拼接。

## 账号和直连

账号通过管理后台配置，存放在data/netdisk，文件0600。网页、TVBox、猫影视和Emby复用宿主账号，源无需实现平台登录或将凭据下发客户端。账号更新/移除后旧引用失效。

115默认使用与客户端匹配的User-Agent取临时地址，Cookie不下发；光鸭保留平台账号权限与流量限制。网页视频元素不能随意设置User-Agent，因此跨浏览器/IP/客户端应分别验证，不能把同机成功当成异地一定可播。

默认由客户端直连临时地址。`delivery: 'proxy'` 是显式中转模式，仍需符合票据和出口权限；失败不自动回退代理。光鸭按需转存默认关闭，开启后只在CokeTV专用目录添加所选视频副本并复用，不移动、删除或覆盖原内容。

## 调试与验收

在独立临时数据目录测试，不拿正式账号文件做删除实验。固定样本覆盖分页、目录、临时地址、平台错误、账号撤销、引用作用域和播放权限；实际账号操作另行按授权范围验收。

可用 `node scripts/netdisk-verify.mjs` 启动本机临时验证入口。按脚本要求设置独立 `NETDISK_TEST_DIR` 和 `NETDISK_TEST_PASSWORD`，可选端口；不要公开该调试服务或在日志里记录账号凭据。完整主程序仍以管理后台和受订阅约束的播放入口为准。

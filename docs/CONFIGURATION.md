# 配置与源包

## 启动配置

可以复制 `.env.example` 为 `.env`，或在启动命令中传入环境变量。

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `HOST` | `0.0.0.0` | 监听地址 |
| `PORT` | `54058` | 服务端口 |
| `ADMIN_PASSWORD` | 未设置 | 未设置时读取 data/admin.json；首次进入管理后台时创建管理密码，观影无需密码 |
| `DATA_DIR` | 项目 data 目录 | 自定义运行数据位置 |
| `PYTHON_PATH` | `python3` | 首次初始化的 Python 解释器路径 |
| `PHP_PATH` | `php` | 首次初始化的 PHP 解释器路径 |
| `CHROME_PATH` | 空 | 首次初始化的 Chrome/Chromium 路径 |
| `TRUST_PROXY` | 未设置 | 值为 1 时信任反向代理头 |

已有数据时，以 GUI 保存的解释器设置为准。对外地址和执行超时在设置页修改。`.env` 与运行数据不进入仓库。

## 本源参数与环境变量

扩展参数指定当前实例使用的站点地址、配置 URL 或其他脚本定义的值。环境变量用于 Cookie、Token 和脚本通过 `ENV.get()` 读取的配置。

每个源实例独立保存环境变量，优先级为「本源值 → 全局默认值 → ENV.get 的默认参数」。空文本、0 和 false 是显式值；移除键后恢复继承。

`ENV.set()` / `ENV.delete()` 在执行期间只修改当前源的配置，异步辅助库读取跟随源上下文；宿主的 `process.env` 不随源切换。Cookie 等敏感表单值默认隐藏，已配置的敏感值在本源日志中遮蔽，不加入 TVBox 输出。源主动返回敏感业务数据时仍需修正源逻辑。

代码、扩展参数和环境变量分别保存。存在未保存修改时提示退出，接口验证要求先保存。

## ZIP 结构

可以在 ZIP 根目录直接放源脚本，也可以使用明确的目录：

```text
spider/js/源.js
spider/js_dr2/源.js
spider/catvod/源.js
spider/catLib/辅助.js
spider/py/源.py
spider/php/源.php
spider/js/_lib辅助.js
json/源参数.json
jx/解析器.js
```

根目录的 py/php 按后缀识别，JS 依据明确的 lang 标记或 CatVod 导出格式识别。无法判定的 JS/辅助库在选文件后确认运行格式。明确目录优先于格式推断。

ZIP 在所有路径、大小与语法检查完成后写入，拒绝越界路径和符号链接。最多 1000 个文件，单文件解压不超过 8MB，总解压不超过 32MB。更新已有脚本保留历史版本。

## TVBox 链接导入

在源管理点击“导入 → TVBox 链接”，粘贴 HTTP/HTTPS 配置地址，读取后勾选要导入的站点。预览不会保存或执行远程脚本。

- `sites` 直接引用的 JS、Python、PHP 脚本会下载并做语法检查；Python/PHP 需要 `Spider` 入口，JS 支持 drpyS、DR2 和 CatVod。配置使用 drpy 加载器并把 JS 规则放在 `ext` 时提取规则文件；无法判定的 JS 选择 drpyS 或 DR2 后再导入。
- TVBox type 0（XML）/type 1（JSON）采集接口读取并验证后，生成 CatVod 引擎的 JS 源脚本，支持分类、搜索、详情与播放。`categories` 保留为分类范围，非直接媒体地址继续使用解析配置。
- 站点名称、搜索能力和扩展参数保留，相对脚本和参数地址按最终配置地址解析。CatVod 静态相对/HTTP 模块依赖会下载为独立辅助库，既有 `assets://` 库要求本地已存在。
- Android JAR、远程 T4 服务、无法读取的接口、缺少入口/辅助依赖或语法错误会显示跳过原因。语法/协议通过不代表第三方站点长期可用或所有视频实际可播；Python/PHP 第三方依赖仍由运行环境提供。
- 重复导入相同来源及参数会去重；已有脚本内容不同则新增独立版本，不覆盖原文件、源参数或订阅。新增实例默认启用，可再加入所需订阅。

预览有效期 15 分钟，一次最多 500 个站点，配置最多 8MB、单个脚本/接口响应最多 2MB，读取资源总计最多 32MB。最多四路并发，每次读取超时 8 秒，总读取超时 120 秒。链接预览和提交都要求管理密码。

## 插件、解析器与浏览器

设置页保留解析器、直播与外部插件配置。插件使用原 `.plugins.js` 数组格式，二进制及资源放在 `data/runtime/plugins/`。启用插件时，首次运行源按需启动插件管理器。

浏览器能力使用 `puppeteer-core`，不随 npm 安装 Chromium；按需指定已有浏览器路径。Python/PHP 和站点专用依赖由部署环境提供。

## 网页播放与解析

首页 `/`、源浏览、搜索、详情和播放公开访问，管理页 `/admin` 和源编辑页要求管理密码。首次部署未创建管理密码也能观影；首次进入管理后台才创建密码。公开源列表仅包含启用源的 ID、名称、语言引擎和搜索/筛选能力，不返回源参数、ENV、脚本、订阅或运行设置。TVBox 订阅继续使用原 Token。

从侧栏或管理页右上角“网页观影”进入。桌面顶部与手机底部的“影视站”均打开选源列表，选择源后可分类浏览、按源搜索、查看详情、选集和切换线路。点击搜索框展开推荐与本地搜索记录，输入影片名后点击搜索按钮/图标或按回车提交。搜索不依赖首页请求成功；不支持搜索的源会提示切换源。停用源不能继续执行或播放。观看历史、续播位置和收藏保存在浏览器 localStorage，不写入服务端用户配置。

源返回 `parse: 0` 时直接经媒体代理播放，代理保留源返回的请求头、Range、HLS 分片与密钥地址。浏览器媒体请求使用服务端签发的 12 小时临时凭证，只能访问媒体和所属源的代理，不能访问管理接口、源 API 或 TVBox 订阅；服务重启后需要重新选择剧集。

需要解析时，设置页的 `parses` 数组可以配置以下类型：

```json
[
  {"name": "JSON 解析", "type": 1, "url": "https://parser.example/?url="},
  {"name": "本地脚本", "type": 2, "url": "/parse/my-parser"},
  {"name": "网页解析", "type": 0, "url": "https://player.example/?url="}
]
```

JSON 解析应返回 `{url, header?}` 或 `{data: {url, header?}}`，本地脚本使用现有 `jx/` 解析协议。自动模式优先 JSON 或本地脚本；网页解析需手动选择，在受限 iframe 中播放。解析地址后追加经过 URL 编码的原始视频地址。网页解析是否允许嵌入由其服务决定。

## 备份与恢复

完整备份整个 `data/`。GUI 配置导出仅包含实例、订阅、设置及本源环境配置，不含脚本与插件文件。

导入配置恢复实例、订阅和本源变量，运行解释器路径保留当前机器设置。旧备份没有本源变量字段时，保留现有源配置。

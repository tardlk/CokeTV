# 配置与源包

## 启动配置

可以复制 `.env.example` 为 `.env`，或在启动命令中传入环境变量。

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `HOST` | `0.0.0.0` | 监听地址 |
| `PORT` | `54058` | 服务端口 |
| `ADMIN_PASSWORD` | 未设置 | 仅在尚未创建管理密码时预设管理密码；已有 data/admin.json 中的密码优先，不会被该变量重置。未预设时，首次进入后台直接创建密码；观影无需密码 |
| `PUID` | `1000` | Docker 入口准备 data 属主及运行服务所用 UID；仅容器入口生效，要求 1–2147483647 的十进制整数 |
| `PGID` | `1000` | Docker 入口准备 data 属组及运行服务所用 GID；例如 NAS 为 1000:10 时填 10；取值要求同 PUID |
| `DATA_DIR` | 项目 data 目录 | 自定义运行数据位置 |
| `PYTHON_PATH` | `python3` | 首次初始化的 Python 解释器路径 |
| `PHP_PATH` | `php` | 首次初始化的 PHP 解释器路径 |
| `CHROME_PATH` | 空 | 首次初始化的 Chrome/Chromium 路径 |
| `TRUST_PROXY` | 未设置 | 值为 1 时信任反向代理头 |

已有数据时，以 GUI 保存的解释器设置为准。对外地址和执行超时在设置页修改。`.env` 与运行数据不进入仓库。

源码启动时由 dotenv 读取项目 `.env`，已在进程中设置的同名变量优先。Compose 显式向容器传入 `TZ`、`PUID` 和 `PGID`，后两项从同目录 `.env` 或启动 Compose 的 shell 读取（未设置时各自默认1000），主机 `.env` 不会自动成为容器环境；需要其他变量时，在服务的 `environment` 中显式声明，或通过 `docker run -e` 提供。容器中的解释器、浏览器和数据路径均指容器内路径。变量传入规则见 [Docker Compose 官方说明](https://docs.docker.com/compose/how-tos/environment-variables/set-environment-variables/)。

PUID/PGID 的非法值（包括0和空值）在初始化 data 前拒绝启动。它们不改变 NAS 用户账号，仅用于专用数据目录属主和容器进程；不要与 Compose `user:` 混用，显式 Docker 用户会跳过 root 初始化并优先决定进程身份。源码运行不使用这两个变量。

通过 `ADMIN_PASSWORD` 初始化时，KDF 结果只保留在服务内存，不会自动把该密码保存成 `admin.json`；重启需继续提供变量。保存变量的 `.env`、Compose 配置或密码管理工具由部署者自行保护。

管理密码只保存加盐 KDF 结果（`data/admin.json` 为 `{version, salt, hash}`，0600），不再落盘明文；旧的明文格式会在**首次成功登录后**自动迁移。首装（未设密码）时，进入管理后台填写新密码和确认密码即可创建密码。服务不生成或打印初始化码；升级启动时清理旧版 `data/setup-code.txt`，保留已有密码和其他运行数据。未设置密码时，首个成功提交密码的人完成后台初始化，已有密码不能通过首次设密入口重置。

代理出口与参数文件安全开关（设置页「代理与参数安全」分组，随「保存设置」一起提交）：

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| `allowPrivateTargets` | `true` | 控制宿主媒体与 `/http` 对内网/回环/链路本地目标的访问；公网部署建议关闭，宿主登记的本机回环 origin 另作内部调用豁免。 |
| `targetAllowlist` | `[]` | 非空时只允许名单内 host 或 CIDR（设置页每行一条）。 |
| `jsonPublic` | `false` | `/json/` 参数文件默认只对管理员、订阅 Token 或源内部请求开放；开启后恢复旧的匿名可读行为。 |

宿主媒体转发与 `/http` 在每次连接/重定向前检查目标：IPv4、IPv6 与 IPv4 映射 IPv6 按字节判定；已登记的云元数据地址/主机名（`169.254.169.254` 等）永久拒绝，白名单与本机 origin 不豁免。关闭内网时，除宿主明确登记的本机回环 origin 外，任何 DNS 答案含内网地址都会拒绝；空/无效 DNS 答案也拒绝。IP/CIDR 名单支持 IPv4/IPv6，实际连接仅使用匹配并通过检查的地址，不二次解析；保留原域名的 Host、TLS SNI 和证书校验。相关安全修复已发行，当前源码与镜像验收记录见 [接手入口](AI_HANDOFF.md#0-当前接手入口先看本节)；这些设置不是源脚本或外部插件的网络沙箱，源脚本的同权限执行边界仍见 README。

源内部调用的 `/http` 保留 `{status, headers, data}` 返回格式和 Axios 的参数、请求体、响应类型及重定向语义：301/302 的 POST、303 的非 GET/HEAD 转成 GET 并丢弃请求体相关头；307/308 保留方法与请求体；更换主机或 HTTPS 降级时丢弃 Cookie/Authorization 等敏感头（沿用原 Axios 对同端口子域的保留规则），重定向重新生成 Host。`maxRedirects` 默认为 21，可设 0–21，0 返回首跳。每跳重新检查并绑定地址，整条请求沿用设置页超时预算。宿主 `/http` 不读取 `HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY` 环境代理，避免代理重新解析目标。

公开接口与 `/admin/*` 的限流阈值用环境变量调整：`RATE_LIMIT_PER_MINUTE`（默认 1200）与 `ADMIN_AUTH_FAIL_PER_MINUTE`（默认 20，按鉴权失败计数）。仅媒体转发路由的 GET/HEAD 请求携带有效、绑定当前目标 URL 的 `proxy` 票据时豁免公开限流；会执行源逻辑的 `/proxy/:module/*` 即使带有效媒体票据也照常限流。`TRUST_PROXY=1` 时 `request.ip` 取自 `X-Forwarded-For`，必须确保前置代理可信且会覆写该头，否则限流可被伪造 IP 绕过。

## 本源参数与环境变量

扩展参数指定当前实例使用的站点地址、配置 URL 或其他脚本定义的值。本源环境配置可保存 Cookie、Token 等键值；JavaScript 执行上下文中的 `ENV.get()` 用于读取这些配置。

每个源实例独立保存环境变量，优先级为「本源值 → 全局默认值 → ENV.get 的默认参数」。空文本、0 和 false 是显式值；移除键后恢复继承。

JavaScript 的 `ENV.set()` / `ENV.delete()` 在执行期间只修改当前源的配置，异步辅助库读取跟随源上下文；宿主的 `process.env` 不随源切换。Python/PHP 没有自动注入同名 `ENV.get()` 接口，本源键值也不会自动映射为 `os.environ` / `getenv()`；这两类源继续使用各自原有的扩展参数和配置协议。Cookie 等敏感表单值默认隐藏，已配置的敏感值在本源日志中遮蔽，不加入 TVBox 输出。源主动返回敏感业务数据时仍需修正源逻辑。

宿主保存全局/每源 ENV、状态、插件配置和管理凭据时，临时文件和原子替换后的文件均明确为 0600；全局 ENV 在启动同步时也保持此权限。设置保存、配置导入和引擎 ENV 写入均保留该规则，不依赖进程 umask 或替换后的单次 chmod。

PHP 桥接调用失败时接口返回固定的 `PHP 源执行失败`，不包含子进程命令、源参数、ENV 路径或原始 traceback。进入源编辑页查看管理诊断日志可见异常原因和方法，私有参数（包括 JSON 子值）、嵌套 ENV 和运行路径被遮蔽；公开请求不能读取诊断日志。

代码、扩展参数和环境变量分别保存。存在未保存修改时提示退出，接口验证要求先保存。

## 删除源与重新导入

单个和批量删除使用同一确认流程。默认仅移除选中的源实例及所有订阅中的引用，保留脚本、历史版本和本源 ENV；可通过“新建实例”继续使用保留脚本。

勾选“同时清理本源配置、闲置脚本及历史版本”后，会删除所选实例的 ENV。只有脚本已没有其他实例引用时，才删除该脚本文件及其历史版本；共享脚本、其他实例的配置、辅助库及未选中的孤立脚本均保留。清理的文件不能在后台恢复，重要脚本应先备份。文件操作或状态保存失败时会回滚。

重新上传同名脚本，或导入包含相同脚本内容的 ZIP 时，若该脚本已没有实例，会重新创建启用实例。仍有实例时保持其参数、启用状态和数量。曾删除的订阅成员不会自动恢复，需要在订阅管理中重新选择源。ZIP 中与已有文件内容冲突的情况仍会拒绝覆盖。

管理 API 的 `DELETE /admin/instances/:id` 和 `DELETE /admin/instances/batch` 支持 JSON 布尔字段 `deleteScripts`，默认 `false`；批量请求同时提供 `ids`。返回 `deleted`（实例数）、`deletedScripts`（清理脚本数）和 `retainedScripts`（保留脚本数），清理选项会在实际提交时重新检查共享引用。

## ZIP 结构

可以在 ZIP 根目录直接放源脚本，也可以使用明确的目录：

```text
spider/js/源.js
spider/js_dr2/源.js
spider/catvod/源.js
spider/catLib/辅助.js
spider/py/源.py
spider/php/源.php
spider/js/_lib辅助.js
json/源参数.json
jx/解析器.js
```

根目录的 py/php 按后缀识别，JS 依据明确的 lang 标记或 CatVod 导出格式识别。无法判定的 JS/辅助库在选文件后确认运行格式。明确目录优先于格式推断。CatVod导出标记包括 `__jsEvalReturn`、`export default` 和默认导出的别名/重导出；原版模块正文直接保留，避免被误当密文解码。仅有命名导出的模块按CatVod归类，但是否能运行仍取决于原版内核行为。

ZIP 在所有路径、大小与语法检查完成后写入，拒绝压缩包中的越界路径和符号链接条目。最多 1000 个文件，单文件解压不超过 8MB，总解压不超过 32MB。同名且内容相同的文件复用；内容不同则整包拒绝，不覆盖已有脚本、辅助库或参数文件。文件写入或状态保存失败会撤回本次整包修改。需要更新已有脚本时，请使用源编辑页，保存成功后保留历史版本；保存失败会恢复原脚本和历史记录。若文件系统故障使回滚自身失败，服务会明确报错并保留 `.rollback` 备份；这不等于进程强杀或断电时的跨文件持久事务保证。

## 网盘账号与 115 分享

爬虫作者需要的返回格式、代码示例与开发排错，集中在 [网盘开发指南](NETDISK_DEVELOPMENT.md)。

管理后台“网盘管理”以115、光鸭两张平台卡片展示“未配置/已保存授权”和保存时间。点击“配置授权/管理授权”或编辑图标打开弹窗，分为“扫码登录”和“使用已有登录信息”；关闭弹窗、取消扫码或切换登录方式后停止继续轮询。每个平台保留一个共享账号，不需要迁移已有数据。115支持扫码或粘贴包含UID、CID、SEID的Cookie；设备类型应与已有Cookie一致，同类设备登录可能影响已有会话，建议选择不常用的设备。光鸭可导入访问令牌、刷新令牌、客户端ID和设备ID，提交时验证账号并自动刷新令牌。已有Cookie和Token不会回显，输入值保存后清空；“已保存”仅表示本地存有授权，“刷新状态”也不代表远端实时验证。光鸭按需转存选项放在光鸭授权弹窗内。

卡片的移除按钮会先确认，仅删除对应本机授权文件，保留云盘文件和另一网盘账号。原账号引用及待确认扫码会失效，移除前启动的扫码不能重新写回授权；重新授权即可继续使用。提交时检查授权版本，其他页面已更新授权时拒绝旧移除请求，请刷新后重试。已下发的平台直链仍由平台控制有效期。

源在标准详情 `vod_play_url` 返回完整 115 或光鸭分享链接，亦支持 `push://` 后的 URL 编码链接。115 提取码使用 `password`，光鸭使用 `code`。光鸭官网常附 `#/share`，源应去掉该片段或用 push 包装，避免与分集分隔符冲突。仅在 lazy 返回分享链接的脚本需要调整详情输出。无需把账号凭据放入源 ENV。

账号分别保存于 `data/netdisk/115.json`、`data/netdisk/guangya.json`，目录 0700、文件 0600；状态、管理导出与订阅不包含凭据。备份整个 data 会包含授权，需私密保存。源脚本仍与宿主同权限，这不是脚本沙箱。

统一网盘在网页、TVBox、猫影视默认返回临时平台媒体地址，由客户端直接获取视频。NAS只处理目录、取地址与必要转存API，不转发视频流；失败不会自动回退中转。115按请求浏览器User-Agent取地址，原生客户端携带必要媒体头；光鸭当前返回地址不附账号头。引用绑定源及各自账号，重新登录会拒绝旧引用，自动刷新光鸭令牌保留引用；已下发直链的有效期由平台控制，宿主不能追溯撤销。浏览器编码、HLS跨域及异地公网出口需分别实测。显式 delivery: proxy 兼容旧票据与范围校验。

115不转存。光鸭先尝试分享直链；平台返回需要保存的143/207时，只有开启“允许按需转存到 CokeTV 专用目录”才执行转存。默认关闭；开启后仅新增所选视频到 `CokeTV/item-<分享及文件标识哈希>`，并发与重启复用已有副本，不上传、移动、覆盖或删除文件，也不自动清理。副本占用光鸭账号容量，管理员可在官网自行管理；关闭选项阻止后续转存，不删除副本。平台流量、会员或权限限制仍可能阻止播放，不通过伪造订单或客户端权限绕过。

不自动添加搜索源；资源源必须实际返回光鸭分享，登录不会使115源自动搜索光鸭。原画解码取决于客户端，大体积MKV跳转可能需要缓冲。临时115验证工具见DEVELOPMENT，不是第二套生产服务。

## TVBox 链接导入

在源管理点击“导入 → TVBox 链接”，粘贴 HTTP/HTTPS 配置地址，读取后勾选要导入的站点。预览不会保存或执行远程脚本。CatVod脚本沿用与文件/ZIP入口相同的导出识别，支持下载相对ESM依赖；通过语法检查不代表站点或所有模块写法实际可运行。

- `sites` 直接引用的 JS、Python、PHP 脚本会下载并做语法检查；Python/PHP 需要 `Spider` 入口，JS 支持 drpyS、DR2 和 CatVod。配置使用 drpy 加载器并把 JS 规则放在 `ext` 时提取规则文件；无法判定的 JS 选择 drpyS 或 DR2 后再导入。

DR2在TVBox订阅中按原版输出type3，api指向原版客户端运行库，ext指向该订阅内源脚本的受保护地址；实例参数通过ext地址的params传给运行库。停用/删除订阅、修改Token、移除源或停用源会撤销相应脚本下载权限。ENV和账号文件不会随脚本下发。DR2客户端脚本不代表可以直接由网页或Emby服务端执行，原服务端兼容尝试入口继续保留。
- TVBox type 0（XML）/type 1（JSON）采集接口读取并验证后，生成 CatVod 引擎的 JS 源脚本，支持分类、搜索、详情与播放。`categories` 保留为分类范围，非直接媒体地址继续使用解析配置。
- 站点名称、搜索能力和扩展参数保留，相对脚本和参数地址按最终配置地址解析。CatVod 静态相对/HTTP 模块依赖会下载为独立辅助库，既有 `assets://` 库要求本地已存在。
- Android JAR、远程 T4 服务、无法读取的接口、缺少入口/辅助依赖或语法错误会显示跳过原因。语法/协议通过不代表第三方站点长期可用或所有视频实际可播；Python/PHP 第三方依赖仍由运行环境提供。
- 重复导入相同来源及参数会去重；已有脚本内容不同则新增独立版本，不覆盖原文件、源参数或订阅。新增实例默认启用，可再加入所需订阅。

预览有效期 15 分钟，一次最多 500 个站点，配置最多 8MB、单个脚本/接口响应最多 2MB，读取资源总计最多 32MB。最多四路并发，每次读取超时 8 秒，总读取超时 120 秒。链接预览和提交都要求管理密码。

## 插件、解析器与浏览器

设置页保留解析器、直播与外部插件配置。插件使用原 `.plugins.js` 数组格式，二进制及资源放在 `data/runtime/plugins/`。启用插件时，首次运行源按需启动插件管理器。

浏览器能力使用 `puppeteer-core`，不随 npm 安装 Chromium；按需指定已有浏览器路径。Python/PHP 和站点专用依赖由部署环境提供。

## 订阅访问令牌

新建或配置订阅时，“访问令牌”可以自定义，支持1–200位英文字母、数字、短横线（`-`）和下划线（`_`），不能包含空格。新建留空会自动生成随机令牌；编辑现有订阅时不能为空。不同订阅不能共用令牌，包括已停用的订阅。

后台优先提供短链接：TVBox为 `/tvbox/<令牌>`，猫影视为 `/cat/<令牌>/index.js.md5`，不再需要手填订阅ID。原 `/s/<令牌>` 入口继续兼容。短链接按唯一令牌查找订阅；旧备份中的重复令牌不会任意选中订阅，后台保留带ID的兼容地址。

保存新的令牌后，原TVBox和猫影视链接立即失效，需要在播放器更新链接。“重置链接”仍可生成随机令牌。令牌随订阅持久化，服务重启后保留。

管理API `POST /admin/subscriptions` 和 `PUT /admin/subscriptions/:id` 接受可选的 `token` 字段：新建时省略或空字符串使用随机令牌；编辑时省略保留现值。非法值返回400，跨订阅重复返回409，失败不会修改订阅。既有导入令牌原样保存时保持兼容。订阅令牌不能用于登录管理后台，公开源列表不会返回它。

## 猫影视 / Miraplay 订阅

管理后台的每个订阅可以同时提供 TVBox 配置和猫影视 Node.js 入口，选择源和顺序共用。节点程序是 `src/cat-client.cjs`，独立 CommonJS `start(config)` / `stop()`，仅依赖 Node 内置模块，通过 `catServerFactory` 接入宿主，始终监听 `127.0.0.1:0`。不在手机运行服务器里的 Python/PHP 或完整源脚本。

短下载目录为 `/cat/<订阅Token>/`，原 `/cat/<订阅ID>/<订阅Token>/` 继续兼容。两个入口都直接提供 `index.js`、`index.js.md5`、`index.config.js`、`index.config.js.md5`。两个摘要分别由最终响应字节计算；模块配置只含 `version: 1` 与 `endpoint`。采用路径凭证以支持按同目录读取配套文件的客户端；不要公开分享链接、连接配置或带完整路径的反向代理访问日志。响应使用 `private, no-store`，不写入正式运行目录、不产生每订阅构建副本。

短入口直接返回四文件，配套配置中的endpoint也使用短目录，无需依赖重定向。两种目录共用相同鉴权、业务动作和媒体处理；短入口同样检查订阅启用、源成员、当前令牌及播放范围，修改令牌后旧短目录失效。

连接程序每次处理本地 `GET /config` 都访问远端 `/manifest`，取得最新站点与顺序，不依赖文件摘要变化来刷新源列表。源增减和排序不改变连接配置字节；发布新程序或变更连接地址时相应摘要改变。四文件下载需要当前有效订阅凭证，停用、删除、重置 Token 后旧入口失效。

本地业务前缀 `/spider/coketv_<实例ID>/3` 实现 JSON POST `init/home/category/detail/search/play`，另兼容 `homeVod`。服务器只接收这组动作，重新校验订阅与启用实例，不接受自定义引擎、源参数或执行 action。搜索传递中文及页码；分类筛选转换为原引擎 Base64 JSON `ext`；多 ID 详情逐个汇总，兼容只处理首个 ID 的引擎；原源返回的线路与分集字段保留。

播放复用服务器解析。统一115与光鸭默认返回平台媒体直链和必要User-Agent；普通源及显式代理请求的可播放地址签发随机媒体引用，保留 `stream.m3u8` 等格式后缀；所有 HLS 变体、分片、KEY/MAP 都改写为同订阅、同源的私有媒体路径。猫影视清单忽略播放器的 Range 探测，取得完整清单后改写；无扩展名清单以实际 Content-Type 识别，遇到 206 后去掉 Range 重新获取一次。MP4 和分片继续支持 Range。新媒体请求重新检查订阅 Token、实例启用状态与成员关系。有效媒体引用的 GET/HEAD 不耗尽公开接口限流预算，文件/发现/源 API 仍限流，非法媒体引用不豁免。客户端已缓存的媒体和正在传输的请求不追溯回收。

无服务器解析的普通网页请求宿主 `catDartServerPort` 的 sniff 能力；没有能力或没有结果时明确失败。源网页带服务器请求头时要求配置服务器解析，避免把私密头发给手机。2026-10-08 用户确认 iOS Miraplay 可通过 HTTP 局域网四文件入口导入，并播放生成 MP4 / 加密 HLS 样片；精确版本未提供。嗅探仅有本地消息模拟证据，手机拖动/切集与其他客户端、真实站点播放仍需分别验收。

## 网页播放与解析

首页 `/`、源浏览、搜索、详情和播放公开访问，管理页 `/admin` 和源编辑页要求管理密码。首次部署未创建管理密码也能观影；首次进入管理后台直接创建密码（见「启动配置」）。公开源列表仅包含启用源的 ID、名称、语言引擎和搜索/筛选能力，不返回源参数、ENV、脚本、订阅或运行设置。TVBox 订阅继续使用原 Token。

从侧栏或管理页右上角“网页观影”进入。桌面顶部与手机底部的“影视站”均打开选源列表，选择源后可分类浏览、按源搜索、查看详情、选集和切换线路。点击搜索框展开推荐与本地搜索记录，输入影片名后点击搜索按钮/图标或按回车提交。搜索不依赖首页请求成功；不支持搜索的源会提示切换源。停用源不能继续执行或播放。观看历史、续播位置和收藏保存在浏览器 localStorage，不写入服务端用户配置。

统一115与光鸭默认由客户端直连；其他源返回 `parse: 0` 时经媒体代理播放，代理保留源返回的请求头、Range、HLS 分片与密钥地址。浏览器媒体请求使用最长有效期 12 小时的**服务端随机能力票据**：票据固定 43 字符（256 位随机数），上游 URL 和 Cookie/Authorization 等请求头保存在服务端，客户端不能从票据解码出这些值。`media` 票据在 `/watch/media/<ticket>` 只抓绑定的 URL 并使用绑定的请求头，同时允许访问所属源的 `/proxy/:module/*`（该入口只绑定源、不绑定 URL，并受公开限流约束）；`proxy` 票据用于 URL 绑定的媒体转发，HLS 各层清单、分片、KEY/MAP 改写时签发独立票据，继承源范围及网盘账号版本，不能更换绑定的目标地址。两类票据均**不能**用于访问管理接口、源 API 或 TVBox 订阅。票据存储上限为 50000 条、64 MiB 载荷；签发时回收过期票据，容量不足时淘汰最旧票据，读取不续期。过期、淘汰或服务重启后需重新选择剧集；单条载荷超出总容量时返回 503，不截短 URL 或请求头。当前发行和发布前后原生容器证据见 [接手入口](AI_HANDOFF.md#0-当前接手入口先看本节)。

媒体转发入口 `/mediaProxy`、`/file-proxy/proxy`、`/unified-proxy/proxy` 和 `/m3u8-proxy/*` 使用一致的解包规则：`url` 支持明文或 base64 HTTP/HTTPS 地址；`headers`（优先）和旧 `header` 支持 JSON 或 base64 UTF-8 JSON 对象，也兼容额外一层 URL 编码及旧 Python 辅助函数未转义的 base64 加号。`form=base64` 不改变字段优先级。字段同时存在时，即使 `headers` 无效也不回退到 `header`。非法 JSON/base64、数组/标量、非字符串值、非法 HTTP 头名或值（含换行、无法作为 HTTP 头值的 Unicode）返回 400；URL 中既有签名百分号编码不重复解码。

订阅 Token 调用继续屏蔽 Cookie、Authorization、Host、内部凭据和转发/连接头；管理员与内部运行时可显式提供 Cookie/Authorization 等媒体业务头，但入站管理 Basic 和内部密钥不会自动传到外站。源返回和能力票据绑定的头保留源凭据；有效的 URL 绑定票据优先使用已绑定头，忽略调用方头参数。源播放结果或 `toBytes=2/3` 返回本服务旧式 `/mediaProxy` URL 时，宿主解出目标与头再签发能力，匿名 GET/HEAD、Range 和 HLS 后续请求保持可用；这不授予匿名用户自行构造代理 URL 的权限。

`/json/` 下的源参数文件默认不匿名可读（可能含 Cookie/Token）：外部匿名请求被拒绝，源自身的回环请求带内部凭据放行，管理员与订阅 Token 也可读取。需要旧的公开行为时把 `jsonPublic` 设为 `true`。

需要解析时，设置页的 `parses` 数组可以配置以下类型：

```json
[
  {"name": "JSON 解析", "type": 1, "url": "https://parser.example/?url="},
  {"name": "本地脚本", "type": 2, "url": "/parse/my-parser"},
  {"name": "网页解析", "type": 0, "url": "https://player.example/?url="}
]
```

JSON 解析应返回 `{url, header?}` 或 `{data: {url, header?}}`，本地脚本使用现有 `jx/` 解析协议。自动模式优先 JSON 或本地脚本；网页解析需手动选择，在受限 iframe 中播放。解析地址后追加经过 URL 编码的原始视频地址。网页解析是否允许嵌入由其服务决定。

## Emby 兼容服务

后台“订阅管理”→某条订阅的“订阅链接”→Emby，提供三项独立复制：服务器根地址、固定用户名 `coke`、本订阅Token作为密码。没有独立服务页面、全局启用开关、账号或媒体库创建步骤。只展示唯一启用订阅内的启用源；原有1–200字符自定义Token继续适用，密码精确匹配。管理密码仅用于后台；播放器根地址为 `http://服务器IP:54058`，`/emby` 兼容前缀也走同一授权。

打开有效订阅的Emby标签，或播放器首次读取目录时，自动串行准备各源的推荐作品，每源单次最多20部；推荐为空时尝试首个分类的第一页。源目录以标准电影/剧集两个视图展示，底层只查询一次。每源累计缓存最多100部，优先保留收藏、已看、进度和最近播放记录所引用作品；正常访问距上次尝试10分钟后按需刷新，失败至少间隔60秒重试。没有后台定时全站扫描。首次无缓存的目录请求最多等待15秒，仍未完成会提示稍后刷新；已有缓存可立即返回。失败作品保留旧目录，全失败不覆盖旧库。

`SearchTerm` 仅搜索已准备内容，不实时搜索全站。条目ID与电影/剧集视图ID持久稳定，媒体列表准确分页；快照缓存最多2分钟，源停用/移出订阅立即生效。类型依源元数据和明确季集标记推断；模糊线路分别展示作品版本，明确同季同集时才合并MediaSources。旧手动目录保留并复用，不要求重建。

单作品最多2000个原始播放项，单源缓存最多10000个规范条目，全服务目录最多20000项/20MiB，物理源目录最多32个。目录、ServerId、按订阅隔离的进度和会话哈希保存在 `data/emby/emby.sqlite`；未使用且没有旧数据库时，启动不创建数据库。协议首次访问按需打开；匿名发现和错误登录不执行源。旧 `settings.json` 保留但不再控制启停。复用现有SQLite WASM依赖，目录0700、数据库0600；损坏文件保留并报错。每订阅最多32个设备会话、全服务最多4096个会话，数据库记录载荷上限128MiB（另有SQLite页/索引开销，空闲页可复用）。完整备份先停止服务，再备份整个data。

观看会话最长30天；退出撤销当前会话，订阅停用、删除、Token修改或重复使旧会话失效。不同订阅隔离收藏、已看及进度，同订阅设备共享；改Token后重登仍保留原记录。网页localStorage历史不自动迁入；初版独立账号及历史保留但不用于登录或自动合并。

115/光鸭每次实际播放刷新目录引用并取临时地址，保持客户端User-Agent，NAS不自动回退网盘中转；准备目录不下载视频或触发转存。需要特殊请求头、异地出口或不支持的编码时仍可能失败。普通源媒体继续授权代理，GET/HEAD/Range/HLS子媒体继承用户/订阅/源范围。服务器不新增转码或通用网页嗅探。

## 备份与恢复

停止使用该目录的服务后，备份完整 `data/`，可保留源脚本/辅助资源、实例、订阅、设置、管理密码哈希、统一网盘账号和历史版本。环境变量提供的配置、外部插件目录或资源，以及浏览器 localStorage 中的历史/收藏不一定在该目录内，需要另外备份。备份包含私密凭据，应限制访问。

管理界面已移除配置导入/导出按钮，服务器仍保留需要管理鉴权的 API：`GET /admin/export` 返回状态和本源 ENV；`POST /admin/import` 替换实例与订阅，并恢复提供的本源 ENV。导出不含脚本正文、插件二进制、管理密码配置或统一网盘账号，因此不能代替完整数据备份。导入前必须已有相应脚本；旧备份未提供的本源 ENV 文件会保留。

导入 API 不应用备份的全局 `settings`，当前服务的解释器路径、全局 ENV、解析器及其他设置均保留。完整恢复设置需使用完整 `data/` 备份，并按新部署环境核对路径。

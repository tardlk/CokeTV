# 配置与源包

## 启动配置

可以复制 `.env.example` 为 `.env`，或在启动命令中传入环境变量。

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `HOST` | `0.0.0.0` | 监听地址 |
| `PORT` | `54058` | 服务端口 |
| `ADMIN_PASSWORD` | 未设置 | 未设置时读取 data/admin.json；全新部署首次进入直接创建密码，没有初始值 |
| `DATA_DIR` | 项目 data 目录 | 自定义运行数据位置 |
| `PYTHON_PATH` | `python3` | 首次初始化的 Python 解释器路径 |
| `PHP_PATH` | `php` | 首次初始化的 PHP 解释器路径 |
| `CHROME_PATH` | 空 | 首次初始化的 Chrome/Chromium 路径 |
| `TRUST_PROXY` | 未设置 | 值为 1 时信任反向代理头 |

已有数据时，以 GUI 保存的解释器设置为准。对外地址和执行超时在设置页修改。`.env` 与运行数据不进入仓库。

## 本源参数与环境变量

扩展参数指定当前实例使用的站点地址、配置 URL 或其他脚本定义的值。环境变量用于 Cookie、Token 和脚本通过 `ENV.get()` 读取的配置。

每个源实例独立保存环境变量，优先级为「本源值 → 全局默认值 → ENV.get 的默认参数」。空文本、0 和 false 是显式值；移除键后恢复继承。

`ENV.set()` / `ENV.delete()` 在执行期间只修改当前源的配置，异步辅助库读取跟随源上下文；宿主的 `process.env` 不随源切换。Cookie 等敏感表单值默认隐藏，已配置的敏感值在本源日志中遮蔽，不加入 TVBox 输出。源主动返回敏感业务数据时仍需修正源逻辑。

代码、扩展参数和环境变量分别保存。存在未保存修改时提示退出，接口验证要求先保存。

## ZIP 结构

可以在 ZIP 根目录直接放源脚本，也可以使用明确的目录：

```text
spider/js/源.js
spider/js_dr2/源.js
spider/catvod/源.js
spider/catLib/辅助.js
spider/py/源.py
spider/php/源.php
spider/js/_lib辅助.js
json/源参数.json
jx/解析器.js
```

根目录的 py/php 按后缀识别，JS 依据明确的 lang 标记或 CatVod 导出格式识别。无法判定的 JS/辅助库在选文件后确认运行格式。明确目录优先于格式推断。

ZIP 在所有路径、大小与语法检查完成后写入，拒绝越界路径和符号链接。最多 1000 个文件，单文件解压不超过 8MB，总解压不超过 32MB。更新已有脚本保留历史版本。

## 插件、解析器与浏览器

设置页保留解析器、直播与外部插件配置。插件使用原 `.plugins.js` 数组格式，二进制及资源放在 `data/runtime/plugins/`。启用插件时，首次运行源按需启动插件管理器。

浏览器能力使用 `puppeteer-core`，不随 npm 安装 Chromium；按需指定已有浏览器路径。Python/PHP 和站点专用依赖由部署环境提供。

## 备份与恢复

完整备份整个 `data/`。GUI 配置导出仅包含实例、订阅、设置及本源环境配置，不含脚本与插件文件。

导入配置恢复实例、订阅和本源变量，运行解释器路径保留当前机器设置。旧备份没有本源变量字段时，保留现有源配置。

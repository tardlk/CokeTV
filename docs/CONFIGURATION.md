# 配置与使用

## 启动配置

Node.js 22 是唯一语言运行环境。`HOST` 默认 `0.0.0.0`，`PORT` 默认 `54058`，`DATA_DIR` 默认项目内 `data/`；`TZ` 可设 `Asia/Shanghai`。`ADMIN_PASSWORD` 仅在未创建密码时生效。`TRUST_PROXY=1` 只用于可信且会覆写转发头的反向代理。

Docker 使用 `PUID`/`PGID`（默认 1000:1000，禁止 0/空值/非数字）准备专用数据目录，随后普通账号执行。卷应仅包含 CokeTV 数据；入口不跟随符号链接，拒绝硬链接、特殊文件与跨文件系统挂载，避免权限修复影响其他文件。显式 Docker `user` 跳过权限初始化。

## 运行日志

日志默认同时输出到 stdio（单行 JSON，`docker logs` 可见）和 `data/logs/coketv.log`（文件 0600、目录 0700，单文件 5 MiB，保留 3 个历史文件）。后台“运行维护 → 运行日志”可查看最近 400 条、按级别过滤并下载整份日志；下载前会先落盘再读取。

- `LOG_FILE=0` 关闭文件日志；也可设为绝对路径或相对数据目录的路径。
- `LOG_MAX_BYTES` 调整单文件上限，`LOG_KEEP` 调整保留的历史文件数。
- `LOG_STDOUT=0` 关闭 stdio 输出（文件日志仍保留）。
- URL 查询中的 token、`Authorization`/`Cookie` 头与 `password=` 类赋值会在写入前替换为 `[redacted]`；源脚本自己打印的敏感内容不会被自动识别，日志仍应按私密数据处理。

## drpy3 脚本

后台新建、上传和编辑统一使用 drpy3，不再选择执行引擎。一个最小源为：

```js
export default {
    meta: {title: '我的源', lang: 'dr3'},
    rule: {host: '', class_name: '电影', class_url: 'movie'},
};
```

可按需要添加 `async init(ctx, extend)`、`home(ctx, filter)`、`homeVod(ctx)`、`category(ctx, tid, pg, filter, extend)`、`search(ctx, wd, quick, pg)`、`detail(ctx, id)`、`play(ctx, flag, id, flags)`、`proxy(ctx, params)`、`action(ctx, name, value)`。返回 TVBox 对象结构；详情含 `vod_play_from/vod_play_url`。宿主对多个详情 ID 逐一调用并合并。

网络与解析使用 `ctx.req`、`ctx.pdfh/pdfa/pd/pdfl` 等标准 API，CryptoJS 等库及纯工具由官方运行库提供。`ctx.store` 按实例持久化到 `runtime/data/drpy3/`，worker 重启后保留；删除脚本时一并清理关联源的此缓存。多清晰度 `urls` 数组完整保留，并将第一个地址提供给共享网页/Emby 播放流程。

后台不再提供独立“设置”页面；源参数与本源ENV仍在各源编辑页配置。已有全局默认ENV、解析器/直播与后台策略保留兼容，不会因删除页面清空。

源的扩展参数通过 `init(ctx, extend)` 传入。宿主上下文位于 `HostEnv.env`；`ENV.get/set/delete` 提供本源变量读写，未定义的源变量回退全局值。变量文件不写入进程级环境变量；错误日志对原始/编码参数和嵌套凭据脱敏。

JS 模块与源同权限执行；只使用可信代码。小说、漫画、站点专用交互和网页嗅探是否可用取决于客户端能力，不能仅凭引擎加载成功认定所有源都可播放。

## 文件与 ZIP 导入

单文件入口使用 `.js`；顶层 `_` 前缀文件视为辅助模块。ZIP 可直接在根目录放入口，或指定目录：

```text
spider/js_dr3/源.js
spider/js_dr3/lib/helper.mjs
spider/js_dr3/lib/helper.cjs
spider/js_dr3/lib/module.wasm
json/参数.json
jx/解析.js
```

原生模块可使用 `import {defineSource} from 'drpy3'`；相对 ESM/CJS 与 `?bytes` 资产导入均受支持。子目录文件不自动注册为源，顶层辅助 JS 使用 `_` 前缀。资源文件必须一起提供；CJS shim 仅支持随源相对模块及 `drpy3`，复杂模块可预打包或使用原生 ESM。

ZIP 拒绝越界、隐藏路径和符号链接；最多 1000 文件，单个解压不超过 8 MiB、合计不超过 32 MiB。相同内容复用，不同内容拒绝覆盖；写入或状态保存失败会回滚本次文件操作，回滚失败时保留 `.rollback` 备份并明确报错。这不等于断电时的跨文件事务保证。

“导入脚本”直接选择本地JS或ZIP，不提供配置链接下载、远程依赖抓取或JSON/XML采集源生成。脚本依赖由作者随ZIP提供；drpy3脚本本身仍可按需要请求和解析站点接口。

## 本源配置和删除

代码、扩展参数、ENV 分别保存；未保存时禁用接口验证，离开页面会提示保留或放弃。源参数/ENV 仅管理员可读；源的实际网络请求和账号权限仍由对应站点决定。

确认删除后，实际移除脚本文件、历史版本、该脚本所有关联源的ENV及持久KV，并移除订阅引用。旧数据中多个源共用一个脚本时一并删除，确认框显示关联数量；批量删除按脚本去重。未使用脚本同样显示在管理列表供删除，不自动清理其他脚本或共享辅助模块。文件或状态失败会回滚。本机/升级备份中的历史副本不属于本次删除范围。

不再提供“新建实例”或“扫描源目录”入口/API，也不会启动或导入时扫描无关文件。新建/导入脚本时自动建立对应源；同内容重新导入可恢复旧版本遗留的孤立源，但不会恢复已移除的订阅授权。

## 多引擎版本升级与迁移

v1 状态首次升级到 v2 时，先将专用数据目录复制到 `data/backups/before-drpy3-*`，排除备份目录自身和依赖软链接，备份目录 0700、普通私密文件 0600，然后刷新 drpy3 运行库。旧源不再执行；原文件、版本、参数、ENV、订阅引用保留并标记“待迁移”。后台可读取并改写代码，点击“保存为 drpy3”后将共享该脚本的实例切到新脚本，保持实例 ID、参数、ENV 与订阅关系，并恢复升级前的启用状态。

不自动翻译或执行旧脚本。改写后的代码需符合 drpy3 格式并通过语法检查；迁移写入失败时回滚新文件与引用。原旧脚本保留用于人工比对。备份可能含完整凭据，不应公开下载或共享。

回退前停止服务，使用与旧代码版本配套的升级前 data 备份，恢复时排除当前运行写入，避免两个版本同时访问。v2 导出配置仅包含状态和 ENV，不是完整脚本备份；完整恢复应备份整个专用 data 目录，或使用“运行维护”中的数据快照。

## 数据快照与恢复

服务启动 60 秒后检查一次快照，之后按 `BACKUP_INTERVAL_HOURS`（默认 24 小时）自动创建，保留最近 `BACKUP_KEEP`（默认 7）份，位于 `data/backups/`；快照文件 0600、目录 0700，不含可重建的 `runtime/libs` 与 `node_modules` 链接。

快照内容包括 `state.json`、`admin.json`、`revisions/`、`runtime/spider/`、`runtime/config/`、`runtime/data/`、`runtime/json/` 和 `runtime/jx/`，覆盖管理状态、凭据哈希、源脚本与历史、源 ENV、持久 KV、参数文件与解析脚本。源脚本和凭据都在其中，下载或转存时按私密数据保管。

后台“运行维护 → 数据快照”可立即创建并下载；删除脚本、批量迁移和导入配置前也会自动补一份快照（10 分钟内已有快照则复用），失败只记警告、不阻断操作。恢复步骤：停止服务 → 先备份当前 `data/` → 将 zip 解压覆盖到 `data/` 根目录 → 启动；不要让新旧进程同时写同一目录。旧版 `/admin/export` 只导出状态与 ENV，不包含脚本文件，完整恢复以本快照为准。

## 订阅与 Emby

订阅链接自动跟随浏览器当前访问的协议、域名或IP和端口。例如通过 `http://abc.com:54058/admin` 访问时，链接以 `http://abc.com:54058` 开头；改用内网IP访问，链接随之改用该IP。TVBox、猫影视和Emby采用相同规则，无需配置固定对外地址。后端按当前请求地址生成源接口与代理地址；旧配置中的 `publicUrl` 不再生效。

反向代理应保留访问Host；HTTPS终止或改写Host时，由可信代理覆盖 `X-Forwarded-Host`、`X-Forwarded-Proto`，并显式设置 `TRUST_PROXY=1`。默认不信任转发头。当前管理页面使用服务根路径，固定对外地址和自定义地址前缀不再作为设置项提供。

执行超时使用内部默认值：普通源操作30秒，交互action60秒；首页home和homeVod分别计时。设置页不再提供“连接与运行”或“检测环境”。

TVBox：`/tvbox/<Token>`，所有站点是服务器 type4 API。猫影视：`/cat/<Token>/index.js.md5`，轻量连接程序在客户端调用服务器；服务器保管脚本和 ENV。订阅停用、删除、Token 修改或源移除使旧访问失效。Token 不应写入公开文档。

订阅链接弹窗中的 Emby 使用服务根地址（例如 `http://服务器IP:54058`）、用户名 `coke`、密码为对应订阅 Token。自动准备所选启用源的有限推荐目录；不默认全站扫描。稳定媒体 ID、播放状态和会话按订阅隔离，重复 Token 拒绝登录；保留 `/emby` 前缀兼容。客户端解码能力和公网可用性需分别验证。

## 网盘账号与播放

115/光鸭账号保存在 data/netdisk 私密文件中，后台不回显凭据。源详情返回分享链接后由宿主展开分集和获取临时地址；默认客户端直连，失败不自动回退服务器中转。账号 Cookie 不下发客户端。

光鸭按需转存默认关闭；开启后只在 CokeTV 专用目录新增选中视频副本并复用，保留平台权限和流量限制，不删除或移动原内容。更换/移除本机授权会撤销旧播放引用，不触碰云盘另一账号或原文件。开发契约见 NETDISK_DEVELOPMENT.md。

## 播放、代理与解析

网页播放器支持现有 HLS、FLV/TS、浏览器原生媒体；不提供服务器转码。浏览器播放不要求管理密码。普通源请求头留在服务器，由短期媒体票据绑定 URL 与权限；支持 GET/HEAD/Range、HLS 子清单、KEY/MAP 和分片派生票据。源代理五元组保持文本、base64二进制、302和流式回包。

可配置外部 JSON/网页解析地址。`jx/` 内的本地解析脚本须改为 drpy3 格式，入口使用 `play(ctx, flag, id)`；旧 drpyS `jx` 脚本不会由旧引擎执行。FTP/WebDAV 辅助网关按需启动，继续要求对应身份与出口权限。

参数文件 `/json/*` 默认私有；管理员、有效订阅与内部调用可按权限读取。匿名媒体及订阅出口禁止私网/回环/链路本地/元数据；管理员/内部源的可信出口受 `allowPrivateTargets` 和 `targetAllowlist` 控制。这些策略在后台保留，设置页不再显示“代理与参数安全”模块；保存其他设置不会重置已有策略。高级部署的策略与信任边界见 SECURITY.md。

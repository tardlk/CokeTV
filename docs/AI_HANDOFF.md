# CokeTV 接手记录

更新：2026-10-25。当前源码版本 **0.2.0**，用户已明确改为 **只保留 drpy3 一个源执行引擎**；原“保留 drpy-node 全部旧源”的范围已被取代。工作方式继续直接在 main，不主动创建分支或 PR。此前发布的镜像和本次本地源码不同，未经流水线发布不能宣称latest已更新。

## 当前架构

- `engine/libs/drpy3/`：上游 e5b89fd779de2a7552feec74d5bd020962ccd2f2 四文件原包，MIT；engine/UPSTREAM.json登记哈希。内置load2x保持原样，CokeTV不提供独立DR2入口。
- `src/drpy3.js`、`drpy3-loader.mjs`：HostEnv、标准库投影、ESM/CJS和字节资产、持久KV、多个详情ID聚合、多清晰度默认地址。源调用自己的服务地址时改走内部回环，重定向移除内部凭据。
- `src/worker.js` / `runner.js`：按需drpy3子进程、串行队列、超时回收与脱敏日志；无Python守护或旧插件启动。FTP/WebDAV和源自定义WS仍按需提供宿主能力。
- `src/host/`：独立HTML解析、JSONPath、ENV及网关辅助；来源与本地哈希在UPSTREAM。宿主修改进入src，不修改官方引擎原包。
- `src/store.js`：数据版本v2、事务/历史、v1预备份与旧源标记、显式代码迁移。数据只在data，发行始终零预置源。
- 网页、TVBox、猫影视、Emby和115/光鸭继续通过统一内容服务。CatVod执行器已删除，猫影视连接程序保留；TVBox配置链接导入和采集JSON/XML脚本生成器已移除。

## 旧数据处理

v1首次启动先备份原数据至backups/before-drpy3-*（排除备份本身与依赖链接），再刷新运行库。旧源停止执行、标记待迁移，原脚本/历史/ENV/参数和订阅引用保留。公开/订阅目录过滤旧源，API不能重新启用旧引擎。

后台读取旧代码后人工改写，保存为drpy3；保持共享该脚本的原实例ID、ENV、参数与订阅引用，并恢复原启用状态。文件名冲突自动采用独立名称，不覆盖已有源；迁移失败回滚文件和状态。回退应停止服务并成对恢复旧代码及升级前data备份，不让两个版本同时写同一目录。

升级与协议回归在临时目录完成。随后本地预览已初始化data，并按用户要求导入爱看机器人drpy3脚本；当前实际源、账号与配置以磁盘数据为准，不能自动覆盖或清空。该站点脚本与本机调试资料不进入发行树。NAS未部署本轮版本。

## 已完成实现

移除drpyS、独立DR2客户端库、CatVod、HIPY、PHP执行器、桥接及旧源专用库；移除旧基线对照脚本与专项测试，保留并迁移公共协议/安全回归。后台新建/导入固定drpy3，设置中不再出现Python/PHP/浏览器路径或旧引擎插件。本地JS/ZIP导入支持模块和WASM；旧格式明确拒绝。TVBox链接导入页面、预览/提交API、远程依赖下载、CMS生成器及coketv/cms别名已删除，直接JSON5生产依赖已移除。新建与上传不再自动识别或选择引擎；观影和订阅选择器删除引擎筛选，管理列表只在有旧源时提供迁移状态筛选，不再重复显示引擎类型列。删除旧map.txt自动导入，保留版本升级备份与待迁移代码读取。本地解析器固定使用drpy3，并覆盖网页播放和/parse入口。

2026-10-25：删除整个“连接与运行”设置模块及 `/admin/dependencies`，移除可配置对外地址和执行超时。订阅窗口直接使用window.location.origin，TVBox/猫影视/Emby一致；后端使用Fastify请求protocol/host生成接口与代理地址，默认忽略转发头，显式TRUST_PROXY=1时按可信代理转发头还原地址。同源保护使用同一来源规则，旧publicUrl不再额外放行其他Origin。旧数据中的publicUrl/timeout不再影响运行，保存设置时不再写入；未手动修改现有用户配置。普通源操作默认30秒，action60秒；保留超时回收保护。

同日删除“代理与参数安全”整个界面与前端表单状态，当时设置页仅保留全局默认ENV及订阅扩展。后台策略与高级配置兼容保留；保存其他设置时，不重置被隐藏的jsonPublic/allowPrivateTargets/targetAllowlist。用户data保持不变。

随后按用户要求删除整个设置页面和侧栏入口，以及其前端状态、保存逻辑与专属样式。后台运行配置/高级管理接口保留兼容，已有全局ENV、解析器、直播及安全策略不清空；本源参数和ENV仍在源编辑页管理。

本轮按用户要求改为脚本级真删除：DELETE /admin/scripts/:id 和 /admin/scripts/batch 调用Store.deleteScripts，实际删除脚本/历史/全部关联源ENV与持久KV并移除订阅引用，事务失败回滚。共享脚本的全部源一并删除，确认框明确提示数量；遗留孤立脚本进入管理列表可删除。移除实例新建与目录扫描入口/API，以及旧实例删除API和软删除选项，不再内部扫描；导入/新建脚本自动注册对应源。现有运行脚本仍留给用户确认删除，未自动清理s.js或爱看机器人。

网页观影对没有分类和首页影片、但可以搜索的源显示“请搜索影片”与直接聚焦搜索框的按钮，不再一律显示“暂无影片”。首页/搜索响应可选的 notice 仅按纯文本显示（最多500字符），用于说明站点浏览限制；切换查询时清除旧提示，不修改官方引擎。站点脚本和登录资料仍仅保存在忽略的本机运行目录。

生产依赖只保留宿主所需包，前端构建工具和测试库归开发依赖。Docker不安装Python/PHP、浏览器或ffmpeg，保留证书和权限初始化工具。GitHub Verify与原生amd64候选矩阵已同步；发布仍须核对同一artifact/image ID/revision，不能重建后直接发布。
